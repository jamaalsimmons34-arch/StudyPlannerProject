# Smart Study Planner System

A Java-based academic planning application that helps students monitor their academic performance and develop effective study habits. Users enter their course names, current grade percentages, and credit hours, and the program calculates a weighted semester GPA, assigns letter grades, identifies the highest-priority course needing attention, and generates personalized weekly study recommendations.

The application uses object-oriented programming principles through a custom `Course` class, which stores course information and automatically calculates study-hour recommendations based on performance. At the end of execution, a detailed study report is displayed and exported to a text file for future reference.

### Features

* Calculate weighted semester GPA
* Convert percentage grades into GPA points
* Generate letter grades (A–F)
* Recommend weekly study hours based on academic performance
* Identify the course requiring the most attention
* Export study plans and GPA reports to a text file
* Handle multiple courses using arrays and loops

### Technologies & Concepts Used

* Java
* Object-Oriented Programming (Classes & Objects)
* Arrays
* Methods
* For-Each Loops
* Conditional Logic (if/else statements)
* File I/O (FileWriter)
* User Input Handling (Scanner)
* GPA Calculation Algorithms
